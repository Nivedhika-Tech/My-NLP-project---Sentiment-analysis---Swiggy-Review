# My-NLP-project---Sentiment-analysis---Swiggy-Review
This project applies **Natural Language Processing (NLP)** to analyze customer reviews from Swiggy. The goal is to classify reviews into **Positive, Negative, and Neutral sentiments*
## Problem Statement Food delivery platforms rely heavily on customer feedback. Understanding sentiment helps improve: -
- Delivery speed 🚚 
- Food quality 🍲
- Packaging 📦
- Customer support 📞
- Methodology 1.
- **Data Preprocessing** -
- Text cleaning (removing punctuation, stopwords, special characters)
- Tokenization -
-  Lemmatization/Stemming
 **Feature Extraction**
   - Bag of Words
   - TF-IDF - Word Embeddings (Word2Vec, GloVe)
  **Modeling**
 - Logistic Regression
 - Random Forest
 - LSTM (Deep Learning)
 - BERT (experimental)
 **Evaluation**
   - Accuracy, Precision, Recall, F1-score - Confusion Matrix
